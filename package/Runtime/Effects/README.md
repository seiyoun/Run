# Effects モジュール (Shiyuan.Foundation.Effects)

本モジュールは、画面のタップ時やシステムイベントに連動して再生する、クライアント向けの視覚効果（演出エフェクト）の管理および再生システムを提供します。

---

## 主な機能

* **`TouchEffectPlayer`**:
  - 画面クリック・タップした座標に、自動でタップエフェクト（パーティクルなど）を生成・再生し、自動で回収（プール管理）するシステム。

---

## 導入・使用例

### タップエフェクトの設定と自動再生

本モジュールは完全に自動化されています。

1. シーン上に `TouchEffectPlayer` プレハブを配置します（インスペクターで再生したいパーティクルエフェクトのプレハブ、およびタッチ検出カメラを設定します）。
2. アプリを実行すると、Unity の Input System を介してタッチ画面のタッチおよびマウスクリックが自動で検知され、その座標にエフェクトが自動再生されます。
3. コードから手動で再生処理を呼び出す必要はありません。

---

## 注意事項

1. **オブジェクトプールとメモリ管理**:
   タップエフェクトは高頻度で生成・破棄が繰り返されるため、本モジュールはオブジェクトプールを使用してインスタンスの再利用を行っています。極端に多くのパーティクルや重いアニメーションを一度に再生するとパフォーマンスが低下する恐れがあるため、アセットの構成には注意してください。
